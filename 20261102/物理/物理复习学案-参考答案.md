## 一、长度测量、机械运动复习

### 长度测量

**1. 长度的国际单位与换算**

- 长度的国际单位：**米（m）**

| 换算 | 结果 |
|:---:|:---:|
| 3 mm | **3×10⁻³ m**（0.003 m） |
| 3 cm | **3×10⁻² m**（0.03 m） |
| 3 dm | **3×10⁻¹ m**（0.3 m） |

**2. 估测常见物体的长度**（参考值）

| 物体 | 参考值 |
|:---:|:---:|
| 拳头宽 | **约 1 dm** |
| 课桌的高度 | **约 0.75 m** |
| 铅笔笔芯直径 | **约 1 mm** |
| 小拇指宽 | **约 1 cm** |
| 手掌的宽 | **约 0.1 m（1 dm）** |

**3. 误差和错误的区别**

- **误差**：测量值与真实值之间的差异，**不能消除，只能减小**（多次测量求平均值、选用精密测量工具、改进测量方法可减小误差）。
- **错误**：由于不遵守仪器的使用规则、读数时粗心等原因造成的，**可以避免**。

**4. 刻度尺测量长度**

- **使用方法**：
  1. 使用前观察它的 **量程（测量范围）和分度值**；
  2. **零刻度线对准被测物体的一端**，有刻度线的一边要 **紧靠被测物体且与被测边保持平行**（不能歪斜）；
  3. 记录时不但要记录数值，还 **必须注明单位**。
- **读数注意**：视线要 **正对刻度线**；要 **估读到分度值的下一位**。
- **物体 A 的长度**：**2.23 cm**（2.22 ~ 2.24 cm 均可）

**5. 会用钟表测量时间**

### 机械运动

**1. 判断运动、静止的方法**

- 先 **选定参照物**，看被研究的物体 **相对于参照物的位置是否随时间变化**：位置变化 → 运动的；位置不变 → 静止的。

**2. 匀速直线运动、变速直线运动的识别方法**

- 看物体在 **相同时间内通过的路程是否相等**：沿直线且相同时间内路程相等（速度不变）→ **匀速直线运动**；路程不相等 → **变速直线运动**。

**3. 速度的概念**

- **路程与时间之比叫做速度**（速度是表示物体运动快慢的物理量）。

**4. 速度的单位及换算**

- **2 m/s = 7.2 km/h**　（1 m/s = 3.6 km/h）

**5. 速度公式及推导**

- 公式：**v = s/t**
- 推导：s = **vt**　　t = **s/v**

**6. 会测速度**

- 器材：**刻度尺**、**秒表（停表）**
- 原理：**v = s/t**

## 二、声现象

### 一、声音的产生

1. 声音是由 **物体的振动** 产生的；**振动** 停止，发声也停止。
   - 管乐器靠里面的 **空气柱** 振动发声；
   - 鼓靠 **鼓面（鼓皮）** 振动发声。

### 二、声音的传播

1. 声音的传播需要 **介质**；**固体**、**液体**、**气体** 都能传声；声音在 **真空** 中不能传播。
2. 声音以 **声波** 的形式传播。
3. 声速的大小与介质的 **种类**、介质的 **温度** 有关。（15 ℃ 时空气中声速为 340 m/s）
4. 声波遇到障碍物会发生 **反射**；能够与原声区分开来的反射声波叫 **回声**。
5. 声音在不同介质中的传播速度一般 **不同**。

### 三、波长、频率和波速

| 概念 | 定义 | 单位 |
|:---:|:---|:---:|
| 波长 | 两个相邻 **波峰** 或两个相邻 **波谷** 之间的距离 | **米（m）** |
| 频率 | 物体 **每秒振动的次数**（振动次数与所用时间之比） | **赫兹（Hz）** |
| 波速 | 波在 **单位时间内传播的距离** | **米/秒（m/s）** |

- 波速、波长和频率的关系：**波速 = 波长 × 频率**（v = λf）

### 四、乐音的三要素

- 乐音的三要素：**音调**、**响度**、**音色**。

| 要素 | 定义 | 决定因素 | 规律 |
|:---:|:---|:---|:---|
| 音调 | 声音的 **高低** | **频率**（振动快慢） | 频率越高，音调越 **高** |
| 响度 | 声音的 **强弱（大小）** | 发声体的 **振幅** | 振幅越大，响度越 **大** |
| 音色 | 声音的品质与特色 | 发声体的 **材料**、**结构** | 不同发声体音色不同 |

### 五、噪声的危害和控制

**1. 噪声的定义**

- 物理角度：物体做 **无规则振动** 时发出的声音。
- 环保角度：**妨碍人们正常休息、学习和工作的声音**。

**2. 声音强弱的等级**

- 以 **分贝（dB）** 为单位表示。

**3. 噪声等级界线**

| 目的 | 声音不能超过 |
|:---|:---:|
| 保护听力 | **90 dB** |
| 保证工作和学习 | **70 dB** |
| 保证休息和睡眠 | **50 dB** |

**4. 控制（减弱）噪声的途径**

- **防止噪声产生（在声源处减弱）**；
- **阻断噪声的传播（在传播过程中减弱）**；
- **防止噪声进入耳朵（在人耳处减弱）**。

## 三、热现象

### 温度

1. 温度：表示物体 **冷热程度** 的物理量；常用单位是 **摄氏度（℃）**。
   - 规定：标准大气压下 **冰水混合物** 温度为 **0** 度，**沸水** 温度为 **100** 度。
   - 气温 -3 ℃ 读作：**负 3 摄氏度（零下 3 摄氏度）**。

### 温度计

2. 测量温度的工具：**温度计**；工作原理：**液体热胀冷缩**。
   - 常用温度计：实验用温度计、寒暑表、体温计。
   - 体温计（括号内答案）：玻璃泡上方有缩口或细管；使用前要 **用力向下甩一甩**；可离开人体读数；分度值为 **0.1 ℃**；量程为 **35 ℃ ~ 42 ℃**。

3. 温度计的使用

| 环节 | 要点 |
|:---|:---|
| 使用前 | 观察它的 **量程（测量范围）**，认清它的 **分度值** |
| 放置 | 玻璃泡 **全部浸入** 被测液体中，不要碰到 **容器底** 和 **容器壁** |
| 读数时机 | 待示数 **稳定** 后再读数 |
| 读数时 | **玻璃泡** 要继续留在被测液体中 |
| 视线 | 与液柱上表面 **相平** |

### 物质的三态与物态变化

4. 物质存在的三种状态：**固态**、**液态**、**气态**。
   - 状态变化（物态变化）：物质由一种状态变成另一种状态的过程。

5. 三态转变图中的六种物态变化（括号内为吸/放热）：

| 变化方向 | 名称 | 吸 / 放热 |
|:---:|:---:|:---:|
| 固态 → 液态 | **熔化** | 吸热 |
| 液态 → 固态 | **凝固** | 放热 |
| 液态 → 气态 | **汽化** | 吸热 |
| 气态 → 液态 | **液化** | 放热 |
| 固态 → 气态 | **升华** | 吸热 |
| 气态 → 固态 | **凝华** | 放热 |

### 熔化和凝固

**6. ① 熔化**

- 定义：**物质从固态变成液态** 叫熔化。

| 对比项 | 晶体 | 非晶体 |
|:---:|:---|:---|
| 常见物质 | **冰、海波、各种金属** | **石蜡、松香、玻璃** |
| 熔化特点 | **不断吸热，温度保持不变** | **不断吸热，温度不断上升** |
| 熔化温度 | 有固定熔化温度 —— **熔点：晶体熔化时的温度** | 没有固定的熔化温度 |
| 熔化条件 | （1）达到熔点；（2）继续吸热 | —— |

**② 凝固**

- 定义：**物质从液态变成固态** 叫凝固。

| 对比项 | 晶体 | 非晶体 |
|:---:|:---|:---|
| 凝固特点 | **不断放热，温度不变** | **不断放热，温度不断降低** |
| 凝固温度 | 有固定凝固温度 —— **凝固点：晶体凝固时的温度** | 没有固定的凝固温度 |
| 凝固条件 | （1）**达到凝固点**；（2）**继续放热** | —— |

- 同种晶体的熔点与凝固点 **相同**。

### 汽化和液化

**7. ① 汽化**

- 定义：**物质从液态变成气态** 叫汽化。汽化的两种方式：**蒸发** 和 **沸腾**。

**蒸发**

- 定义：**在任何温度下都能发生、且只发生在液体表面的汽化现象** 叫做蒸发。
- 影响因素：（1）**液体的温度**；（2）**液体的表面积**；（3）**液体表面上的空气流动**。
- 作用：蒸发 **吸** 热（吸外界或自身的热量），具有 **致冷** 作用。

**沸腾**

- 定义：**在一定温度下，液体内部和表面同时发生的剧烈的汽化现象** 叫沸腾。
- 沸腾特点：**不断吸热，温度不变**。
- 沸点：**液体沸腾时的温度**（不同液体沸点不同）。
- 沸腾条件：（1）**达到沸点**；（2）**继续吸热**。
- 沸点与气压的关系：**气压越大，沸点越高；气压越小，沸点越低**。

**② 液化**

- 定义：**物质从气态变成液态** 叫液化。
- 方法：（1）**降低温度**；（2）**压缩体积**。
- 好处：体积缩小便于运输。
- 作用：液化 **放** 热。

### 升华和凝华

**8. ① 升华**

- 定义：**物质从固态直接变成气态** 的过程。
- 吸 / 放热：**吸** 热。
- 易升华的物质：碘、冰、干冰、樟脑、钨。
- 实例：人工降雨用干冰（发生升华）；白炽灯（钨丝）壁变黑。

**② 凝华**

- 定义：**物质从气态直接变成固态** 的过程。
- 吸 / 放热：**放** 热。
- 实例：霜、玻璃上的冰花、树枝上的雾凇；北方冰冻的衣服也会慢慢变干等。
