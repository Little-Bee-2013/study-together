# 记叙文阅读答题方法（我的笔记）

说明：本文主体是我（学生）自己的说法，只把口诀里每个字的对应关系写清楚，不做发挥。
我用"之类的""你都要知道"带过的地方，标为【待补】，由我自己补。

## 一、概括题

**给已知写未知。** 题里已经给了部分概括内容，要求写出没给的那部分。

分两个小块：

### 1. 仿写

- 字数仿写：写的字数和给的差不多。
- 格式仿写：写的格式和给的一样。

【待补】具体的字数和格式要求，按老师讲的写。

### 2. 原文优先原则

尽量用原文的词汇，而不是自己写。

## 二、含义题

**出题形式**：这句话是什么意思、如何理解这类问法。

**答题公式：表深情**

- 表 = 表层，字面上说的是什么。
- 深 = 深层，背后指的是什么。
- 情 = 情感，表达了什么感情。

【待补】每一层具体怎么写，按老师讲的写。

## 三、赏析题

**出题形式**：好不好、品质分析、表达效果、写批注这类问法。

**答题公式：手法、事件、情感、人物**

- 手法：用了什么手法。
- 事件：写的是什么事。
- 情感：表达了什么情感。
- 人物：表现了人物什么。

【待补】各点的具体写法，按老师讲的写。

## 四、句段作用题

**答题公式：手法、内容、情感、结构**

- 手法：用了什么手法。
- 内容：写了什么内容。
- 情感：表达了什么情感。
- 结构：看这一段在文章的什么位置。

结构分首段、中间段、结尾段三段，每一段都有它对应的那些套话作用。

- 例：首段可以有引领全篇、点题这类。
- 【待补】中间段、结尾段分别有哪些套话，自己按老师给的补上。

## 五、标题作用题

**答题公式：对内线情洗手**

- 对 = 对象
- 内 = 内容
- 线 = 线索
- 情 = 情感
- 洗 = 吸引读者阅读兴趣
- 手 = 手法

【待补】各点的具体写法，按老师讲的写。
